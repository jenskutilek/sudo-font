\section{Variation Axes}

\subsection{Parametric Variation Axes}

\subsubsection{Tabular Width}

The fonts contain a variation axis (tag: XTAB) that controls the tabular width of all glyphs between {\addfontfeature{RawFeature=+frac}404/1000} and {\addfontfeature{RawFeature=+frac}538/1000} (default) of the font size without changing the glyph forms.


\def\xtab{Hamburgefonts 1976}
\begin{itemize}\addfontfeature{RawFeature=+onum}
	\item {\addfontfeature{RawFeature={+axis={wght=200,XTAB=538}}} ExtraLight: \xtab{} (XTAB=538)}
	\item {\addfontfeature{RawFeature={+axis={wght=200,XTAB=504}}} ExtraLight: \xtab{} (XTAB=504)}
	\item {\addfontfeature{RawFeature={+axis={wght=200,XTAB=471}}} ExtraLight: \xtab{} (XTAB=471)}
	\item {\addfontfeature{RawFeature={+axis={wght=200,XTAB=438}}} ExtraLight: \xtab{} (XTAB=438)}
	\item {\addfontfeature{RawFeature={+axis={wght=200,XTAB=404}}} ExtraLight: \xtab{} (XTAB=404)}
\end{itemize}

\subsubsection{Counter Width}

The fonts contain a variation axis (tag: XTRA) that controls the counter width of all glyphs between {\addfontfeature{RawFeature=+frac}243/1000} and {\addfontfeature{RawFeature=+frac}366/1000} (default) of the font size without changing the overall spacing of the font.

\def\xtra{Hamburgefonts 1976}
\begin{itemize}\addfontfeature{RawFeature=+onum}
	\item {\addfontfeature{RawFeature={+axis={wght=200,XTRA=366}}} ExtraLight: \xtra{} (XTRA=366)}
	\item {\addfontfeature{RawFeature={+axis={wght=200,XTRA=335}}} ExtraLight: \xtra{} (XTRA=335)}
	\item {\addfontfeature{RawFeature={+axis={wght=200,XTRA=304}}} ExtraLight: \xtra{} (XTRA=304)}
	\item {\addfontfeature{RawFeature={+axis={wght=200,XTRA=274}}} ExtraLight: \xtra{} (XTRA=274)}
	\item {\addfontfeature{RawFeature={+axis={wght=200,XTRA=243}}} ExtraLight: \xtra{} (XTRA=243)}
\end{itemize}

\subsection{User-Facing Variation Axes}

\subsubsection{Width}

The fonts contain a variation axis (tag: wdth) that combines the XTAB and XTRA axes so the width of the spacing and the outlines can be controlled at the same time. To use this, your text engine needs to support version~2 of the avar OpenType table.

\def\xtra{Hamburgefonts 1976}
\begin{itemize}\addfontfeature{RawFeature=+onum}
	\item {\addfontfeature{RawFeature={+axis={wdth=100,wght=200}}} ExtraLight: \xtra{} (wdth=100)}
	\item {\addfontfeature{RawFeature={+axis={wdth=95,wght=200}}} ExtraLight: \xtra{} (wdth=95)}
	\item {\addfontfeature{RawFeature={+axis={wdth=90,wght=200}}} ExtraLight: \xtra{} (wdth=90)}
	\item {\addfontfeature{RawFeature={+axis={wdth=85,wght=200}}} ExtraLight: \xtra{} (wdth=85)}
	\item {\addfontfeature{RawFeature={+axis={wdth=80,wght=200}}} ExtraLight: \xtra{} (wdth=80)}
	\item {\addfontfeature{RawFeature={+axis={wdth=75,wght=200}}} ExtraLight: \xtra{} (wdth=75)}
\end{itemize}

\subsubsection{Italic}

The fonts contain a variation axis (tag: italic) that switches between upright (0, default) and italic (1) letter posture.
